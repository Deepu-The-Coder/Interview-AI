InterviewAI | Full-Stack Career Intelligence Platform

Engineered a backend-heavy application using Node.js and MongoDB to automate the interview preparation process for job seekers.

Integrated Google Gemini AI to architect a multi-stage workflow: analyzing Job Descriptions, generating match scores, and providing personalized preparation plans.

Developed a dynamic Resume Generator that outputs ATS-friendly resumes in downloadable formats based on AI-driven keyword optimization.

Implemented JWT-based authentication to ensure secure data handling and private storage of user reports and career data.

Designed a scalable REST API to handle large-scale text processing and asynchronous AI requests seamlessly.
